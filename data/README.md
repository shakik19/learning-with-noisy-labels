# Data

Raw data is not committed. Download it into this folder, then `rsync` it to the VM
(see `infra/README.md`).

| File | Needed for | Size | Source |
|---|---|---|---|
| `cifar-10-python.tar.gz` | all experiments (VM) | ~163 MB (170,498,071 bytes) | https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz |
| `CIFAR-10_human.pt` | optional CIFAR-10N runs (Kaggle) | 2,401,007 bytes | https://github.com/UCSC-REAL/cifar-10-100n/raw/main/data/CIFAR-10_human.pt |

```bash
cd data
curl -LO https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz
curl -LO https://github.com/UCSC-REAL/cifar-10-100n/raw/main/data/CIFAR-10_human.pt

md5sum cifar-10-python.tar.gz   # expected: c58f30108f718f92721af3b95e74349a  (torchvision's checksum)
md5sum CIFAR-10_human.pt        # expected: 96644db5574813cae939af5f7f2a0aec

tar -xzf cifar-10-python.tar.gz # -> data/cifar-10-batches-py/
```

Resulting layout (works with `torchvision.datasets.CIFAR10(root="data", download=False)`):

```
data/
├── cifar-10-python.tar.gz
├── cifar-10-batches-py/
│   ├── data_batch_1 … data_batch_5
│   ├── test_batch
│   └── batches.meta
└── CIFAR-10_human.pt
```

Notes

- No other dataset is required. Synthetic label noise is generated by code from a fixed seed and
  saved with each run, so it never needs to be downloaded.
- **CIFAR-10N labels are aligned to the original training-set order** of `data_batch_1 … 5`.
  Load the training set in that order *before* any shuffling or train/validation split.
- `CIFAR-10_human.pt` is a pickled object from the official CIFAR-N repository; load it only with
  code you have read (it is a dict of label arrays: `clean_label`, `aggre_label`, `worse_label`,
  `random_label1-3`).
- On Kaggle, upload both files as a private Kaggle Dataset, or use an existing public CIFAR-10
  dataset there and only upload `CIFAR-10_human.pt`.
